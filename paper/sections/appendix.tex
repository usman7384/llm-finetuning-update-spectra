The effective batch size is 16 (batch 1 with 16 accumulation steps) for full
fine-tuning; LoRA runs use batch 4 with plain AdamW. The base tokenizer of
SmolLM2-360M has no chat template, so SFT borrows the one from
SmolLM2-360M-Instruct. Token budgets for the controls are counted after
truncation to the sequence length, so they match what each run actually
trained on. Seed repeats change both the training seed and the data sample
(42 to 43). Every run records its exact training rows and token count.

Full SFT scored 29.5\% on GSM8K and the base model 34.2\%. The IFEval
recovery varies non-monotonically between ranks, which with one seed per
rank we cannot separate from noise; ranks 64 and 128 produced identical IFEval
scores despite different checkpoints and validation losses. Because the
lowest learning rate won at every rank, the best rate is probably lower still,
and the GSM8K trend should be read with that in mind.
